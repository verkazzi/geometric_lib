# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a



# Общее описание решения
Проект `geometric_lib` - библиотека на языке Python для вычисления площади и периметра геометрических фигур.

Библиотека состоит из двух модулей: вычисления для круга и вычисления для квадрата.



# Описаниe функций

## Модуль circle.py

### def area(r)
Возвращает произведение квадрата числа `r` на число `π`
(площадь круга радиуса `r`)

 **Параметры:**
 `r` (int или float): число (радиус круга)

**Возвращаемое значение:**
 `area`(float): произведение квадрата числа `r` на число 'π' (площадь круга)
        
 **Пример вызова:**
`area(2)`
12.566370614359172

### def perimeter(r)
Возвращает произведение удвоенного числа `r` на число `π`
(длину окружности радиуса `r`)

**Параметры:**
`r` (int или float): число (радиус окружности)

**Возвращаемое значение:**
 `perimeter`(float): произведение удвоенного числа `r` на число `π` (длина окружности)
        
**Пример вызова:**
 `perimeter(2)`
12.566370614359172

## Модуль square.py

### def area(a)
Возвращает квадрат числа `a`
(площадь квадрата со сторной длины `a`)

**Параметры:**
`a`(int или float): число (длина стороны квадрата )

**Возвращаемое значение:**
`area`(int или float): квадрат `a` (площадь квадрата)
        
**Пример вызова:**
 `area(7)`
 49

### def perimeter(a)
Возвращает произведение числа `a` и числа 4
(периметр квадрата со стороной длины `a`)

**Параметры:**
`a`(int или float): число (длина стороны квадрата)
        
**Возвращаемое значение:**
 `perimeter`(int или float): произведение `a` на 4(периметр квадрата с длиной стороной `a`)
        
**Пример вызова:**
`perimeter(10)`
40

## Unit-тестирование

Для проверки правильности работы функций используется встроенный модуль Python `unittest`.

Автоматические тесты расположены в папке `tests`:

- `tests/test_circle.py` — тесты функций площади и периметра круга;
- `tests/test_square.py` — тесты функций площади и периметра квадрата.

Всего разработано 20 Unit-тестов: по 5 тестов для каждой функции.

Проверяются нулевые, целые, дробные, малые и большие значения.
